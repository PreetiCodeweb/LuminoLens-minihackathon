# 🌟 LuminoLens Frontend

A modern, responsive landing page for **LuminoLens** – an innovative blue-light eyewear brand. This frontend project delivers an elegant user interface with animated product cards, interactive modals, and QR code integration for enhanced user experience across devices.

---

## 🖼️ Live Demo

> 🧪 Want to try it out? Open `index.html` in any browser or host it using GitHub Pages, Netlify, or Vercel.

---

## 📌 Features

- ⚡ **Fully responsive layout** using Tailwind CSS
- 💡 **Featured product grid** with smooth animations
- 🔍 **Interactive pop-up modal** for product details
- 📦 **Dynamic product data** handled via JavaScript
- 📱 **QR Code generation** for mobile access
- 💬 **Functional contact form** with visual feedback
- ✨ **Scroll-triggered animations** with `IntersectionObserver`

---

## 🚀 Getting Started

You can run this project directly from your local system — no frameworks or build tools required.

### 🧰 Prerequisites

- Modern web browser (Chrome, Firefox, Safari, etc.)
- Optional: Live server extension (for hot reload during editing)

### 📂 Setup

```bash
git clone https://github.com/your-username/lumino-frontend.git
cd lumino-frontend
```
